# Smart Life Jacket GPS Tracker

Hệ thống áo phao thông minh tích hợp định vị GPS theo thời gian thực sử dụng Leaflet và JavaScript.

## Giới thiệu

Dự án được xây dựng nhằm hỗ trợ theo dõi vị trí của người mặc áo phao trên bản đồ theo thời gian thực.  
Ứng dụng phù hợp cho:

- Giám sát an toàn đường thủy
- Theo dõi cứu hộ
- Quản lí vị trí người dùng trên biển/sông
- Hệ thống cảnh báo khẩn cấp

Bản đồ được hiển thị bằng thư viện Leaflet kết hợp OpenStreetMap.

---

## Công nghệ sử dụng

- HTML5
- CSS3
- JavaScript
- Leaflet.js
- OpenStreetMap API
- Geolocation API

---

## Tính năng

- Hiển thị vị trí hiện tại trên bản đồ
- Theo dõi GPS realtime
- Tự động cập nhật vị trí
- Hiển thị marker người dùng
- Zoom đến vị trí hiện tại
- Hỗ trợ dẫn đường
- Giao diện responsive
- Có thể chạy offline bằng local server
